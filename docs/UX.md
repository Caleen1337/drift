# UX

## Nawigacja

4 zakładki + globalny player:

```
Discover · Search · Library · Me
```

## Discover (home)

- Tryby: **Safe / Balanced / Deep / Chaos** (suwak eksploracji).
- Półki: „Picked for you”, „Go deeper”, „Something unexpected”,
  „Your recent discoveries”.
- Spokojny, bez 30 półek algorytmicznego śmietnika.

## Discovery Feed (główny ekran)

Karta:

```
        [album art]
        Artist
        Track

        Why this?
        „Because you like UK Garage and you haven't explored this scene yet"

        ❤️      👎      ▶
```

Gesty: swipe up → następny, ❤️/👎 → sygnał, ⋯ → więcej akcji
(don't recommend artist/genre, less/more like this, open artist/album/Spotify).

## Player

- ▶ Play here (YouTube Music backend, port Metrolist)
- ↗ Open in Spotify (oficjalny klient, Spotify zapisuje historię)
- swipe up → lyrics, swipe down → queue
- mini-player nad tabbarem

## „Me” — transparentny profil

```
Genres       Electronic  87% █████████░
Artists      Burial      91% █████████░
Novelty      ████████░░
```

Długi press na ❤️ → „What did you like?” (artysta / gatunek / brzmienie /
wokal / produkcja / klimat) — opcjonalny, nie wymuszany.

## Rabbit Hole

Ścieżka „Burial → Untrue → Four Tet → Floating Points → Aphex Twin” —
algorytm widzi, że użytkownik sam poszedł w daną stronę (mocny sygnał).
